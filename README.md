# GIT-Y2 — 黒磯島（Kuroiso-jima / 1985年廃村）3D 孤島探索プロジェクト

周囲を見渡す限りの外洋に囲まれた **2km × 5km** の孤島「黒磯島（1800年代後半開村・1890年炭鉱開坑・1985年廃村）」を、スマホ横画面全画面表示＆一人称視点で探索できる 3D 地形・自然環境基盤です。  
全テクスチャは [`assets/textures/`](assets/textures/) の支給画像36枚から抽出した 212 枚の WebP タイルのみを使用しています。

## 本フェーズの実装内容（地形・配置造成・森林・雑草・徹底最適化）
- **2km × 5km 山岳孤島地形 (`src/world/terrainMath.ts`)**:
  - 南端「漂着浜（Y=2.1m）」の目覚め地点から、平均標高約 **253m** の山腹斜面廃村、標高 **865.0m** の最高峰「黒磯岳主峰」、東山中の「子供たちの秘密基地（Y=376m）」、1890年「旧黒磯炭鉱第一坑口予定地（Y=348m）」、けもの道を抜けた先の北西天然三日月入江「秘境の旧港建設案（PORT01, Y=2.8m）」までを空間ハッシュ加速の連続関数で構築。
  - **全 32 配置予定地の石垣テラス造成済み**（民家×25・商店×2・交番×1・村営公園×1・秘密基地×1・炭鉱坑口×1・旧港×1）。※家屋本体の個別手作業建築・KHDR・Shadow Flame は次フェーズ予定。
  - **完全歩行可能な道路・獣道網**: 海岸林道・3段斜面村道・黒磯林道（山の中の道）・黒磯岳865m山頂獣道・秘密基地分岐獣道・旧港けもの道を自然尾根へドレープ造成。
- **徹底ゲーム最適化（一括読み込みなし）**:
  - **4段階マルチLOD チャンクストリーミング (`src/world/terrainStreamer.ts`)**: `16×40 = 640` チャンク（`128m` 四方）を距離に応じて LOD0〜LOD3 で毎フレーム `4.2ms` 予算内に漸進生成・不要LOD即時解放（常時約 20万〜26万 三角形に抑制）。
  - **3階層ストリーミング植生 (`src/world/foliageStreamer.ts`)**: 遠景森林（`256m` チャンク・軽量シルエット）・近景精密樹木＆苔岩（`128m` チャンク）・GPU頂点シェーダ風揺れ雑草/シダ/ススキ（`64m` マイクロチャンク）を `InstancedMesh` で動的ストリーミング。
- **スマホ横画面全画面 UI & 高解像度・高FPS制御 (`src/ui/hud.ts`, `src/main.ts`)**:
  - `HD (1280×720)` / `FHD (1920×1080)` / `1.5K (2560×1440)` 解像度切替＆`120 FPS` / `無制限 FPS` モード対応。
  - スマホ横画面デュアルタッチ操作（仮想スティック・自動ダッシュ・視点ドラッグ・ジャンプ・しゃがみ）＆PC（WASD・マウス・Shiftダッシュ・Mマップ・Esc設定）。
  - 2km×5km 標高段彩＋等高線インタラクティブ地形図（クリック＆ランドマーク一覧で各地点へ即移動可能）。
