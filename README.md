# GIT-Y2 — 黒磯島（Kuroiso-jima / 1985年廃村）3D 孤島探索プロジェクト

周囲を見渡す限りの外洋に囲まれた **2km × 5km** の孤島「黒磯島（1800年代後半開村・1890年炭鉱開坑・1985年廃村）」を、スマホ横画面全画面表示＆一人称視点で探索できる 3D 廃村探索ゲームです。  
全テクスチャは [`assets/textures/`](assets/textures/) の支給画像36枚から抽出した 212 枚の WebP タイルのみを使用しています。

- **公開ページ（GitHub Pages / `main` 直配信）**: https://sc8z35a-collab.github.io/GIT-Y2/

## 現在の実装状況（Phase 5 完了・全21棟入室可能）
- **2km × 5km 山岳孤島地形 (`src/world/terrainMath.ts`, `src/world/terrainStreamer.ts`)**:
  - 漂着浜（標高 2.1m）から平均標高約 253m の3段山腹斜面廃村、標高 **865.0m** の黒磯岳主峰山頂、東山中の秘密基地（376m）、1890年炭鉱坑口予定地（348m）、北西入江の秘境旧港（2.8m）までを4段階LOD（640区画・毎フレーム 4.2ms 予算）で動的ストリーミング。
- **32樹種・4〜15本枝分かれ・現実密度の超軽量森林 (`src/world/treeArchetypes.ts`, `src/world/foliageStreamer.ts`)**:
  - 杉・檜・黒松・広葉樹・低木・古木の **32種**（全種4〜15本枝分かれ・樹高 `3.4m〜25.5m`）を区画あたり僅か3ドローコールへ静的GPU統合し、島全体で同時約3.6万〜4.0万本の現実密度を実現。
- **完全手作業・非テンプレートの明治〜昭和伝統瓦木造民家 21棟（2〜4階建・全室入室＆階段昇降対応）**:
