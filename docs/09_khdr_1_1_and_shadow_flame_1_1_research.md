## 3. KHDR 1.1 確定アーキテクチャ：独自強化 HDR の 6 大革新技術

KHDR 1.0（[`src/core/khdrPipeline.ts`](../src/core/khdrPipeline.ts)）の「16bit 線形 HDR ＋ 2階層ブルーム ＋ 固定露出」から、**KHDR 1.1** では実証実験に裏付けられた以下の 6 技術を統合する。

1. **`K-Adapt`（GPU完結 1×1 非対称瞳孔順応）**:
   - 4階層ピラミッド最下層 `1/32` バッファ（約 `40×22`）から中央重点加重（空の上端抑制）の平均対数輝度 $\bar{L}_{\log}$ を、CPU リードバック完全ゼロの **1×1 Ping-Pong `RGBA16F` テクスチャ** へ積分。
   - 非対称時定数（縮瞳 $\tau_{\text{up}}=0.55\text{ s}$ / 散瞳 $\tau_{\text{down}}=2.20\text{ s}$）・露出クランプ `[-1.1, +1.4] EV` により、坑口脱出時の眩しさと屋内・炭鉱の暗順応を破綻なく実現。
2. **`Bilateral K-LHE v2`（エッジ保存バイラテラル局所明暗平衡・ハロー `0.00%`）**:
   - `1/4` 周辺輝度参照時に 5 タップ輝度レンジ重み $w_i = \exp\!\left(-\frac{(\log L_i - \log L_0)^2}{2\sigma_r^2}\right)$（**最適値 $\sigma_r = 0.75\text{ EV}$**）を乗じ、黒瓦屋根×青空の `-18.1% / +22.1%` ハローを **完全 `0.00%` 消去** しつつ杉樹皮の微細質感を ~89% 保持。
3. **`4-Tier Dual-Kawase + Spectral Halation`（映画光学 4階層ブルーム＆長波長ハレーション）**:
   - `1/4 → 1/8 → 1/16 → 1/32` の 4 階層へ拡張（`1/16`・`1/32` の追加コスト合計 `< 0.08ms`）。狭域は色相忠実、広域（`1/16`, `1/32`）は 35mm フィルムの赤層後方散乱を模した暖色長波長ハレーションを付与し、炭鉱防爆灯・駐在所赤灯・太陽コロナを映画的に滲ませる。
4. **`K-Volumetric Sun-Shafts`（無料深度バッファ活用・山岳＆巨杉ゴッドレイ）**:
   - `hdrTarget` の `resolveDepthBuffer: true` で追加パスゼロ取得した `uDepthTex` を `1/4` 解像度で参照し、`depth >= 0.99995` の空マスクへ太陽スクリーン座標 $\mathbf{p}_{\text{sun}}$ 向け **12タップ IGN ジッター放射レイマーチ** ＋ **Henyey-Greenstein 位相関数 ($g=0.78$)** を適用（`uCaveFactor`・背光時は自動ゼロ）。
5. **`K-Purkinje`（露出後輝度ゲート暗所プルキンエ視覚）**:
   - 実験 5C の知見に基づき **露出適用後の輝度 `L_exposed`** に対して `smoothstep(0.035, 0.006, L_exposed)` で限定発動。昼間の村・杉葉・民家の暖かい畳部屋には **影響 `0%`** のまま、1890年炭鉱の奥底の無灯岩盤にのみ冷たい桿体シフト（青銀 507nm 寄り）を与え、手元の暖色カンテラとの圧倒的な対比を生む。
6. **`K-Filmic v2`（輝度比フィルム曲線＋一定色相放射脱彩・葉色ズレ `0.00°`）**:
   - 実験 4 で検証済みの「**輝度比トーンマッピング ＋ ハイライト肩のみ無彩色方向へ一定色相放射脱彩**」を採用し、全露出レンジで日本杉・広葉樹の葉色ズレ **`0.00°`** を数学的に厳守する。

## 4. Shadow Flame 1.1 Flash 確定アーキテクチャ：負荷同等以下で 6km 全山に本物の影

1. **`SF-ZeroSwim`（ライト空間テクセルグリッド完全スナップ）**:
   - [`ShadowFlameSystem.update`](../src/core/shadowFlame.ts#L404-L461) のワールド座標丸めを廃し、プレイヤー座標をライトビュー行列 $V_{\text{light}}$ へ射影して 1 テクセル幅 $s = \frac{2\cdot\text{halfExtent}}{\text{mapSize}}$ で厳密量子化＋逆変換（CPU `< 0.002ms`）。斜め歩行・坂道移動時のシャドウ水泳を完全根絶。
2. **`SF-SlopeBias`（受光面傾斜適応マイクロバイアス）**:
   - $\sin\theta = \sqrt{1 - (\mathbf{N}\cdot\mathbf{L})^2}$ に応じて深度バイアスを `baseBias * (0.35 + 1.65 * sinTheta)` へ動的変調。地面・柱根元の Peter-Panning を最小化しつつ北カルデラ絶壁のアクネを根絶。
3. **`SF-MacroHorizon 6km`（ビルド時プリベイク `6.3 KB`・GPUコスト 0 の 6km 全山ホライゾン影）**:
   - ビルド時スクリプトで `public/data/horizon_6km.bin`（`256×512` R8・12m 格子・gzip `6.3 KB`）を事前生成し、起動時に `< 1.5ms` でロード。[`TerrainStreamer`](../src/world/terrainStreamer.ts) の頂点生成時にバイリニア補間して頂点属性 `aHorizonVis` へ焼込。
   - **GPU シャドウマップ 0 枚追加・テクスチャサンプラー 0 個追加・ドローコール 0 増**で、全島陸地の `14.26%`（北カルデラの `42.4%`）に及ぶ黒磯岳 865m 等の真の山影を **Flash 1.1 でも 120 FPS で描画**！
4. **`SF-CloudDrift & Komorebi`（同期雲影＆風揺らぎ木漏れ日・サンプラー消費 0）**:
   - スカイドーム雲と同速度・同方向の 2 オクターブ軽量解析ノイズによる大地形雲影（最大 18% 減光・炭鉱自動ゼロ）＋ 半影帯（`0.05 < sfVis < 0.95`）での時間位相 IGN 木漏れ日微揺らぎ。

## 5. Shadow Flame 1.1 Pro 確定アーキテクチャ：WebGL2 極限 6 層物理シャドウ

1.1 Flash の全 4 技術を土台に、以下の **6 つの高度リアルタイム技術** を搭載する。

1. **`SF-Tri-Cascade`（3段階対数カスケード ＋ 1フレーム最大1カスケード分散更新スケジューラ）**:
   - **C0 (`±28m`, `2048²` = `2.73 cm/texel`, 閾値 `0.35m`)** / **C1 (`±115m`, `2048²` = `11.23 cm/texel`, 閾値 `3.0m`)** / **C2 (`±420m`, `1536²` = `54.69 cm/texel`, 閾値 `16.0m`)** → 以遠は `SF-MacroHorizon 6km` へシームレス接続。
   - サンプラー予算 `地形12 + C0 + C1 + C2 = 15 / 16`（WebGL2 下限厳守）。120FPS 全力疾走中でも **83.5% のフレームで影更新 0**、最大 1 カスケード/frame でスパイク完全ゼロ。
2. **`SF-PCSS v2`（`dZ/dUV` 受光面深度勾配補正付 物理接触硬化）**:
   - `dFdx(sc)`・`dFdy(sc)` の 2×2 ヤコビアン逆行列から受光面傾き $\nabla_{uv} z$ を算出し、8-tap ブロッカー探索＆16-tap 可変 Vogel フィルタの各オフセットへ $z_{\text{cmp}} = z_0 + \text{clamp}(\Delta\mathbf{u}\cdot\nabla_{uv} z, -0.0035, +0.0035)$ を適用。65°絶壁と急勾配瓦屋根の自己暗化を 100% 根絶。
3. **`SF-SSCS`（真・画面空間コンタクトシャドウ / 24-bit `uDepthTex` レイマーチ）**:
   - 実験 2 で 50m 先まで `<= 0.60mm` 精度が実証された `uDepthTex` を用い、距離 `< 45m` の画素へ **6〜8 ステップ IGN ジッター太陽光ビュースペース・レイマーチ**（`0.03m → 0.95m`）を実行。畳縁・障子桟・石垣目地・階段1段ごと・トロッコ車輪下に物理的ミリ単位接地影を刻む。
4. **`SF-GTAO-Lite`（半解像度ホライゾン環境光遮蔽）**:
   - 同一の無料 `uDepthTex` を `1/2` 解像度化し、2軸4方向ホライゾン角積分（IGN回転付）＋ 深度エッジ保存バイラテラルアップサンプリングを実行。全 25 民家屋内・公園遊具下・炭鉱坑木接合部を現実の立体感へ引き締める。
5. **`SF-Canopy SSS`（日本杉・広葉樹 逆光透過光・葉色厳守）**:
   - 影側葉面に $\text{pow}(\max(\mathbf{V}\cdot(-\mathbf{L}), 0), 3.2)$ の逆光透過をベース葉色 `diffuseColor.rgb` 比例で加算（色相無変化で 32 樹種密林の透光感を再現）。
6. **`SF-Dual-Bounce v2`（標高＆洞窟連動・物理2色間接反射影）**:
   - 標高・地表（砂浜暖反射／森林深苔／高山天空青）と `uCaveFactor` へ連動した連続間接バウンス色温度遷移。
