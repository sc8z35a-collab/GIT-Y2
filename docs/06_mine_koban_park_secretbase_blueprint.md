# 黒磯島 1985 — 最終4大ランドマーク詳細設計図（1890年旧黒磯炭鉱地下坑道・黒磯駐在所・見晴らし村営公園・子供たちの山奥の秘密基地）

本設計図は、黒磯島の全32 planned sites を完全制覇する最終4大ランドマーク（**`M01` 旧黒磯炭鉱 第一坑口・地下坑道**・**`K01` 黒磯駐在所（交番）**・**`P01` 見晴らし村営公園**・**`B01` 子供たちの山奥の秘密基地**）の完全手作業設計・間取り・地下坑道構造・歩行導線・マテリアル仕様を定めたものである。

---

## 1. `M01` 旧黒磯炭鉱 第一坑口・地下坑道（1890年開坑・1985年閉山）

### 1.1 地質・配置計画
- **座標**: `(-145, -890, Y = 348.0m, yaw = +0.15 rad)`（黒磯林道 `road_forestry` 沿い・黒磯岳西斜面の断崖直下）
- **山体被り（Overburden）**:
  - `lz = +4 → -16m`: 坑口前広場（標高 `348.0m` 平坦地、林道は `lz ≥ 0` 側を100%非干渉通過）
  - `lz = -20.5 → -30.0m`: 山体斜面立ち上がり帯。`terrainStreamer.ts` にて `lx ∈ [-3.4, +3.4], lz ∈ [-30.0, -20.5]` の最小限メッシュ開口を設け、周囲 `lx ∈ [-12, +12], lz ∈ [-32, -15], Y ∈ [-6, +22]` を手作業の玄武岩・炭層断崖カラー＆切石・赤煉瓦坑門で完全に隙間なく封止。
  - `lz = -30 → -140m`: 頭上山体は `+20m 〜 +185m` の強固な黒磯岳岩盤下となり、全長 **135m・高低差 5.2m・全3分岐** の本格地下炭鉱ダンジョンを形成。
- **地下物理＆大気演出**:
  - `caveOverrides` により坑内全域（`Z: -17 → -142m`, `X: -42 → +38m`, `Y: -8 → +30m`）で地表ハイトフィールド干渉を完全解除。
  - `main.ts` にて入坑深度（`lz = -15 → -28m`）に応じて外光・青空フォグを暗黒炭鉱霧（`#0c1014`）へ滑らかに減衰し、プレイヤー携行の**暖色坑夫カンテラ（Headlamp PointLight）**と坑内主要分岐の**防爆白熱坑道灯×4基**が点灯。

## 2. `K01` 黒磯駐在所（交番・明治29年/1896年築・昭和33年改装・2階建）

- **配置**: `(91, 469, Y = 239.0m, radiusX = 7.2, radiusZ = 6.2, yaw = -0.52 rad)` — 漂着浜から海岸林道を登り切った黒磯村入口三叉路（`(82, 480)`）の北東角に道路非干渉で立地し、正面が三叉路広場を真っ直ぐ見渡す。
- **外観**: 切石腰基礎・白漆喰＆下見板二階建、いぶし銀本瓦入母屋大屋根（鬼瓦×2）、正面玄関庇に灯る**赤色丸型常夜灯（交番赤灯）**＆青ホーロー看板（`enamel_sign_blue`）、屋外木造掲示板（`bulletin_board`・`notice_board`）・島案内板（`island_map_sign`）、西側の巡回自転車トタン庇。
- **1F (`Y = +0.42m`)**: ガラス両開き戸からテラゾー土間へ入室。事務カウンター（`office_counter`）・事件マップ掲示板（`cork_board`）・書類キャビネット・消火器箱・配電盤。奥の北東区画には鉄格子仕切りの簡易保護室兼証拠保管室。
- **2F (`Y = +3.52m`)**: 西木階段から駐在巡査一家の居住区（縁付畳6畳＋床の間・時代箪笥・布団・書棚）および三叉路を一望する正面木製バルコニー高欄。

## 3. `P01` 見晴らし村営公園（1964年整備・1985年閉園）

- **配置**: `(-52, 215, Y = 242.0m, radiusX = 15.5, radiusZ = 12.5, yaw = +0.15 rad)` — 下段村道（`road_village_low`）の東側へ隣接し、西側幅4.6mの石門からそのまま入園可能。
- **区画構成（全29m × 23m・完全歩行＆遊具登頂対応）**:
  1. **西正門＆苔石垣外周**: 切石門柱・島案内図・町内掲示板・苔石舗装園路（`mossy_pavers`）。
  2. **登って滑れる昭和レトロすべり台**: 階段 `stairRun` で地上 `+2.35m` 踊り場へ登頂し、傾斜シュート（歩行スロープ面）で滑り降り可能。
  3. **錆びた二連ブランコ＆3×3×3鉄骨ジャングルジム**: 鋼管Aフレーム・吊り鎖・木座面・格子鉄棒キューブ。
  4. **コンクリート縁砂場＆傾いた木製シーソー**: 粗砂（`sand_coarse`）の砂場と鉄支点シーソー。
  5. **見晴らし本瓦東屋（休憩所）**: 高床木造デッキ・周囲ベンチ・宝形本瓦四方屋根から渓谷対岸の廃村群を展望。
  6. **レトロタイル水飲み場＆入室可能な公園管理小屋兼公衆便所**: 白・青モザイクタイル水場、ベンチ×4、園灯、北隅のコンクリート小屋（`vanity_sink`, `white_bath_tile`, `storage_rack`）。

## 4. `B01` 子供たちの山奥の秘密基地（1980〜1985年・二層構造）

- **配置**: `(430, -580, Y = 376.0m, radiusX = 8.5, radiusZ = 8.0, yaw = -0.80 rad)` — 黒磯岳獣道から分岐する山奥の隠れ道（`trail_secret_base`）終点。東側の到着口を開けた天然苔巨岩の円陣窪地。
- **二層構成**:
  1. **地上焚き火広場 (`Y = 0.0m`)**: 苔巨岩×7の天然障壁、丸石焚き火跡（`charred_soil`＋組んだ流木薪）、丸太ベンチ×3、木箱・段ボール資材置き場、流木の「ひみつきち」手作りアーチ門。
  2. **1F 廃材板＆トタン屋根の秘密隠れ家 (`Y = +0.38m`)**: 村から集めた古板・褪色赤板・青錆＆赤錆トタン・帆布タープで不揃いに組んだ小屋。内部は赤ヴィンテージラグ（`vintage_rug_red`）・リンゴ箱テーブル＆赤座布団・漫画本棚（`filled_bookshelf`）・手描き宝の地図黒板（`chalkboard`＋`island_map_sign`）・コルクボード・宝箱段ボール。
  3. **2F 巨杉の樹上見張りやぐら (`Y = +3.28m`)**: 直径1.3m・樹高11mの古杉の巨木を抱き込むように手作り木階段で登る空中デッキ。流木手摺・赤トタン雨除け・木製望遠鏡支柱を備え、深い杉原生林越しに黒磯岳865m主峰を望む。
