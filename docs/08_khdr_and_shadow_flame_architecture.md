# 08. KHDR（独自強化HDR）& Shadow Flame 1.0（Flash / Pro）独自レンダリング技術設計書

## 1. KHDR（Kuroiso Hyper-Dynamic Range）独自強化HDRパイプライン
従来の単純な ACES トーンマッピングのみのポスト処理を刷新し、黒磯島（3km×6km火山孤島・伝統瓦廃村・1890年地下炭鉱）の極端な明暗差（直射日光の漆喰壁・外洋の太陽反射 vs 濃密な杉林下・庇の影・地下坑道カンテラ光）を破綻なく美しく描画するための独自 16bit 線形 HDR パイプラインを [`src/core/khdrPipeline.ts`](../src/core/khdrPipeline.ts) に開発・実装する。

### 1.1 パイプライン構成（オン/オフ即時切替対応）
1. **16bit Half-Float 線形 HDR シーンバッファ（`RGBA16F` + WebGL2 MSAA）**
   - 従来の 8bit 画面出力で `1.0` 以上が白飛びしていた太陽光・海面ハイライト・白漆喰・1890年炭鉱の防爆灯・駐在所の赤い常夜灯を、`1.0` を超える真の物理輝度空間で保持する。
2. **Karis加重 5-Tap スペクトル抽出 ＋ Dual-Kawase 2階層ピラミッド（1/4 & 1/8 解像度）**
   - 1パスで「**光学ブルーム用高輝度成分（RGB）**」と「**局所周辺対数輝度場（Alpha）**」を同時算出する独自パッキング方式を採用し、追加レンダーターゲット無しで超軽量化（GPU負荷 `< 0.4ms`）を実現。
   - **Soft-Knee スペクトル閾値**（`threshold = 1.05, knee = 0.55`）により、杉や広葉樹の緑葉を濁らせず、真の高輝度ハイライトと炭鉱灯火だけに自然な光学グレアを与える。
3. **K-LHE（Kuroiso Local Highlight-Shadow Equilibrium：局所明暗平衡アルゴリズム）**
   - フル解像度輝度 `L` と 1/8 解像度の周辺対数輝度 `L_surr` の対比から、画面各領域の眼順応をリアルタイム計算。
   - **暗部ディテール救済**: 杉林の下草・瓦屋根の軒下・木造民家の土間などの中暗部ディテールを最大 `+26%` 鮮明化しつつ、地下炭鉱の真暗黒域（`L < 0.008`）は黒浮きさせない。
   - **高輝度ヘッドルーム保護**: 太陽直射の漆喰壁・雲・海面反射を滑らかにロールオフし、階調を保持。
4. **K-Clarity（輝度ガイド局所マイクロコントラスト強調）**
   - 中間調ベルカーブ重み付きの Unsharp Radiance Recovery により、焼杉板・本瓦・火山地層岩壁・樹皮の立体感を際立たせる。
5. **K-Filmic v1（AgXインセット着想・色相保持型フィルミックカーブ）＋ 三角青ノイズディザ**
   - 一般的な ACES で起きがちな「強光下の緑→黄・橙→ピンクへの色相ズレ」を抑える知覚インセット行列を適用し、日本の山林の深い緑（葉色厳守）・外洋の群青・明治木造の温もりを正確に再現。最終段で 8bit バンディング除去ディザを適用。

## 2. Shadow Flame 1.0（独自軽量・超リアルシャドウエンジン）
[`src/core/shadowFlame.ts`](../src/core/shadowFlame.ts) にて Three.js の `ShaderChunk.shadowmap_pars_fragment` および `ShaderChunk.lights_fragment_begin` へ独自シャドウカーネルを直接統合し、全地形チャンク・32拠点建築・4万本超の樹木へ一括適用する。

### 2.1 Shadow Flame 1.0 Flash（超軽量・高実在感モード）
スマホ・高フレームレート環境でも極めて軽く、かつ標準 `PCFSoftShadowMap` を大きく上回る自然な影を実現する独自軽量技術：
1. **SF-BlueNoise Rotated Vogel-6 カーネル**:
   - 標準 `PCFSoft` の格子状9タップ（バイリニア16フェッチ相当）を廃止し、ピクセル毎の **Interleaved Gradient Noise（IGN）回転角** で回す **黄金角 Vogel Spiral 6タップ** へ刷新。テクスチャフェッチを **約33%以上削減** しながら、軒先や枝の斜めエッジに出る格子状ジャギーを完全消滅。
2. **軽量 1536×1536 テンポラルキャッシュ・シャドウマップ（±116m）**:
   - 標準 2048×2048 比で **ラスタライズ画素数を44%削減** し、さらに `autoUpdate = false` による移動距離トリガー更新（`> 1.5m` 移動時またはストリーミング変化時のみ再描画）により静止・視点旋回時のシャドウパス負荷を **0ms** 化。
3. **SF-Frustum Smooth Fade**:
   - シャドウ境界（84%〜100%）を滑らかにフェードアウトし、四角い影切れ線を排除。
4. **SF-SkyBounce 大気散乱ブルースカイ影着色**:
   - 太陽光が遮られた影面に青空からの天空散乱光（淡いセルリアンブルー）を物理比例付与し、影が泥のように黒ずまない立体感を実現（地下炭鉱進入時は太陽光強度に連動し自動で `0.0` 化）。

### 2.2 Shadow Flame 1.0 Pro（次世代・高度物理シャドウモード）
Flash の軽量設計基盤の上に、AAA 級の高度な独自・最先端シャドウ技術を5層統合：
1. **SF-Dual-Cascade ハイブリッド・デュアルカスケード構造（テンポラルキャッシュ付）**:
   - **Cascade 0（近景超高精細・2048×2048・±50m / `4.8cm/texel`）**: 格子戸・縁側手すり・本瓦の凹凸・樹木の小枝までミリ単位の輪郭で接地影を描画（`0.5m` グリッドスナップ更新）。
   - **Cascade 1（遠景ランドスケープ・2048×2048・±245m / 490m四方）**: 廃村全25棟の集落谷全体と中距離森林（`FoliageStreamer` の `midCells` 影も連動有効化！）の雄大な影を遠方まで切れ目なく投影。移動 `> 6.0m` 時のみ更新する **テンポラル・カスケードキャッシュ** により高負荷を抑制。
   - **BRDFゼロ重複設計**: `sunLightFar` は深度マップ供給専用とし、フラグメント側の `RE_Direct` 二重計算を完全スキップ。Cascade 0→1 間は 78%〜96% 帯で IGN ディザ滑らかクロスフェード。
2. **SF-PCSS 真・物理接触硬化ソフトシャドウ（8-Tap Blocker Search + 16-Tap 可変半径 Vogel PCF）**:
   - 近景 Cascade 0 上で 8タップ IGN ブロッカー探索を行い、遮蔽物と受光面の物理距離から半影幅（Penumbra）を動的算出。
   - 柱の根元や軒下などの **接地部分はカミソリのように鋭く**、頭上15mの巨杉の枝葉が地面に落とす影は **空気を含んで柔らかく滲む** 現実の太陽光（視直径 0.53°）を物理再現。さらに完全日向ピクセル（`blockers == 0`）は即時アーリーアウトで高速化。
3. **SF-MicroContact 画面空間マイクロ接地シャドウ**:
   - シャドウマップ解像度以下の数ミリ〜数センチの凹凸（下見板の継ぎ目・瓦溝・苔岩・砂利道）に対し、太陽光ベクトル方向への画面空間輝度微分から方向性マイクロ自己遮蔽をリアルタイム合成。
4. **SF-Horizon 山岳遠景セルフシャドウイング**:
   - 245m カスケード外（3km×6km の遠方連峰・北カルデラ・4水系渓谷）において、法線と太陽光角による谷陰ターミネータ強調を行い、6km 先の尾根まで深い彫刻的陰影を維持。
5. **SF-Dual-Bounce 2色間接反射影（天空青＋地表苔/木漏れ日バウンス）**:
   - 上向き影面には清澄な青空散乱、下向き軒裏・樹冠裏には地表からの柔らかな暖色バウンス光を付与（地下炭鉱では自動消灯）。
