## 伝統日本瓦屋根の立体構造仕様（全10棟共通の本格造形基準）

各家屋の屋根は単なる平板ではなく、日本の伝統瓦建築を立体パーツで組み上げる：
1. **屋根野地板＋化粧垂木（たるき）**: 深い軒出（`0.65m〜1.05m`）の裏面に等間隔で突き出す木製垂木。
2. **立体丸瓦畝（うね）**: 屋根勾配に沿って一定ピッチ（`0.34m〜0.44m`）で並ぶ半円柱／角丸の瓦畝列。
3. **軒丸瓦（のきまるがわら）**: 軒先すべての瓦畝先端に取り付く円筒メダリオン。
4. **多層棟構造（大棟・隅棟・降棟）**: 熨斗瓦（のしがわら）の段積み＋丸冠瓦＋両端の立体角付き**鬼瓦（おにがわら）**。
5. **破風（はふ）・懸魚（げぎょ）**: 入母屋・切妻の三角妻壁（白漆喰・焼杉・木格子）と破風板。
6. **家屋ごとの瓦仕上げ差異**: いぶし銀本瓦（`slate_roof_dark`）、石州赤茶釉薬瓦（`glazed_brown_brick`）、苔むし黒瓦（`dark_slate`＋`deep_moss`）、赤釉薬瓦／赤トタン混成（`red_tin_roof`＋`slate_roof_dark`）、崩落欠損瓦（`H03`, `H05`）。
