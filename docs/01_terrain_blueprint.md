## 3. 道路・獣道ネットワーク設計
すべての道路・獣道は地形生成関数 `sampleTerrain(x, z)` の空間グリッドに事前登録され、自然地形へ勾配制限付きラプラシアン緩和でドレープ（`drapePathOntoMountain`）したうえで**切土・盛土グレーディング**と**路面テクスチャスプラッティング**が一体生成される：

1. **海岸林道（`海岸〜村入口`・道幅 4.6m・最大勾配 18°）**:
   - 漂着浜 `(X:+42, Z:+2158, Y:2.1m)` から山腹の沢沿いをつづら折りで登り、標高 `238m` の村入口（交番前交差点）へ至る約 2.1km の舗装崩れ・砂利林道。
2. **斜面村道 3段ネットワーク（`平均標高 253m`・道幅 4.4〜5.0m・最大勾配 3.4°〜13.9°）**:
   - **下段村道（`Y: 224〜258m`）**: 渓谷寄りの斜面中腹に引かれた生活道（H01〜H08、公園P01へ接続）。
   - **中段本通り（`Y: 238〜278m`）**: 交番（K01）・商店2軒（S01, S02）・見晴らし坂展望カーブ・H09〜H18 を結ぶ基幹斜面道。木製電柱・架空電線・ガードレール・石垣が連なる。
   - **上段山腹道（`Y: 268〜290m`）**: 上部斜面の H19〜H25 を結び、北の山岳林道・山頂獣道へ直結。
3. **山の中の道（`黒磯林道`・道幅 4.2m・最大勾配 22°）**:
   - 上段村道 `(X:-30, Z:-440, Y:278m)` から深い杉林と岩斜面を縫って北上し、**1890年炭鉱坑口予定地（Y:348m）**および西尾根登山口 `(X:-540, Z:-1035)` へ至る未舗装山道。
4. **山頂への獣道（`黒磯岳山頂獣道`・道幅 2.7m・延長 1.54km・完全歩行可能勾配 ≤27°）**:
   - 上段山腹道東端 `(X:+185, Z:-310, Y:290m)` から東尾根へ取り付き、自然尾根の稜線に沿う緩やかなつづら折りで標高 `318m → 479m → 629m → 749m → 865.0m` の主峰山頂（一等三角点・標識・ケルン）へ登り詰める土と樹根の獣道。
5. **秘密基地への獣道（`山奥分岐獣道`・道幅 2.3m・最大勾配 22°）**:
   - 山頂獣道の東尾根分岐 `(X:+352, Z:-525, Y:318m)` から深い杉とシダの森へ逸れ、標高 `376m` の自然窪地「**子供たちの山奥の秘密基地（B01）**」へ至る細道。
6. **港へのけもの道（`北西秘境港ルート`・道幅 2.7m・完全歩行可能）**:
   - 林道西尾根終点 `(X:-540, Z:-1035, Y:425m)` から北西の海岸尾根肩に沿ってジグザグに下り、北西岸の天然三日月入江「**秘境の旧港建設予定地（PORT01, X:-522, Z:-1768, Y:2.8m）**」へ抜けるけもの道。

## 5. 2km × 5km 徹底ゲーム最適化アーキテクチャ
広大な `10 km²` の山岳地形と数万本の木々・雑草を高解像度（HD / FHD / 1.5K）かつ **120 / 無制限FPS** で動作させるための多層最適化：

1. **空間ハッシュ加速地形関数（`SpatialTerrainAccel`）**:
   - 全道路セグメント・全獣道セグメント・全32造成テラスを `128m` 格子へ事前登録。頂点サンプリング時の探索対象を近傍数個に絞り、地形生成を **20倍以上高速化**。
2. **4段階マルチLOD・フレーム予算制御チャンクストリーミング（`TerrainStreamer`）**:
   - `2048m × 5120m` を `16 × 40 = 640` チャンク（`128m × 128m`）へ分割し、**初期一括読み込みを完全廃止**。
   - プレイヤー距離に応じて **LOD0 (`64×64`, 2m間隔, <220m)** / **LOD1 (`32×32`, 4m間隔, <560m)** / **LOD2 (`16×16`, 8m間隔, <1450m)** / **LOD3 (`8×8`, 16m間隔, 遠景水平線)** を毎フレーム最大 `4.5ms` の時間予算内で漸進ビルド＆旧LOD即座 `dispose()`。
   - チャンク境界スカートによりLOD切替時の隙間をゼロ化。常時描画ポリゴン数を約 `20万〜30万` 三角形に制御。
3. **3階層ストリーミング植生エンジン（`FoliageStreamer`）**:
   - **遠景・中景森林（`256m` チャンク、最大視程 `3.2km`）**: 超軽量円錐シルエット杉林・広葉樹を `InstancedMesh` で描画し、865m山頂から見渡す山々全体を途切れなく深い森で覆う。
   - **近景精密樹木（`128m` チャンク、視程 `420m`）**: 幹テクスチャ＋3段枝葉の杉・檜、枝ぶり豊かな広葉樹、苔岩、倒木をストリーミング。
   - **超密集・風揺れ雑草／シダ／ススキ（`64m` マイクロチャンク、視程 `135m`）**: GPU頂点シェーダ風揺れ＋有機的草先アルファカットアウトを用いた交差ブレード群で、道路脇の雑草・林床のシダ・ススキ原をゼロCPU負荷で高密度表現。
4. **8層バイオーム・トライプラナーPBRシェーダ & 大気遠近法フォグ**:
   - ユーザー支給の212枚実テクスチャから海岸砂・黒岩・急崖玄武岩・日向草原・深苔林床・舗装砂利道・土根獣道・高山地衣類岩を自動ブレンドし、日本山岳特有の青みがかった大気遠近法ヘイズで865mの立体感を演出。
